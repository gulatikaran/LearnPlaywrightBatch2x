# Learn Playwright Batch 2x

A comprehensive learning repository for mastering Playwright test automation with JavaScript fundamentals.

## 📚 Course Structure

### Chapter 01 - Basics
- `01_Basics.js` - Introduction to JavaScript basics
- `02_JS.js` - JavaScript fundamentals
- `03_JS_Verify_Setup.js` - Environment setup verification
- `04_HotCode.js` - Hot code reloading and live testing

### Chapter 02 - JavaScript Concepts
- `05_JS_Basics.js` - Core JavaScript concepts for Playwright

### Chapter 03 - Identifier & Literals
- `06_Identifier_Rules.js` - JavaScript identifier naming rules
- `07_Identifier_part2.js` - Advanced identifier patterns
- `08_Comments` - Commenting best practices
- `javascript_identifier_rules.js` - Complete identifier rules with examples
- `vs_code_keyboard_shortcut_mac.md` - VS Code shortcuts for macOS
- `vs_code_keyboard_shortcut_windows.md` - VS Code shortcuts for Windows

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Setup
```bash
# Install dependencies
npm install

# Run a specific file
node chapter_01_Basics/01_Basics.js
```

## 🛠️ Tools & Technologies

1. Start with Chapter 01 for JavaScript basics

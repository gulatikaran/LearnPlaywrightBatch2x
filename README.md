## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Setup
```bash
# Install dependencies
npm install

# Run a specific file
node chapter_01_Basics/01_Basics.js
```

## 📖 Learning Path
1. Start with Chapter 01 for JavaScript basics
2. Move to Chapter 02 for core JS concepts
3. Study Chapter 03 for identifier rules and best practices
4. Explore Chapter 04 for variables, scope, and hoisting
5. Dive into Chapter 05 for literals, strings, and template literals
6. Master Chapter 06 for operators
7. Proceed to Chapter 07 for if-else control flow
8. Learn Chapter 08 for switch statement patterns
9. Practice Chapter 09 for handling user input
10. Understand Chapter 10 for loops and iteration
11. Work with Chapter 11 for arrays
12. Deep-dive Chapter 12 for functions (closures, HOF, pure functions)
13. Manipulate Chapter 13 for strings
14. Model data with Chapter 14 for objects
15. Explore Chapter 15 for 2D arrays
16. Master Chapter 16 for callbacks
17. Advance to Chapter 17 for promises
18. Use Chapter 18 for async/await patterns
19. Apply everything in Chapter 19 for Playwright basics
20. Reference the VS Code shortcut guides for productivity

# Visual Studio Code Keyboard Shortcuts (Windows)

## General
| Shortcut | Action |
|----------|--------|
| `Ctrl + Shift + P`, `F1` | Show Command Palette |
| `Ctrl + P` | Quick Open, Go to File |
| `Ctrl + Shift + N` | New Window |
| `Ctrl + W` | Close Window |
| `Ctrl + ,` | Open Settings |
| `Ctrl + K, Ctrl + S` | Open Keyboard Shortcuts |

## Basic Editing
| Shortcut | Action |
|----------|--------|
| `Ctrl + X` | Cut line (empty selection) |
| `Ctrl + C` | Copy line (empty selection) |
| `Ctrl + ↓/↑` | Move line down/up |
| `Shift + Alt + ↓/↑` | Copy line down/up |
| `Ctrl + Shift + K` | Delete line |
| `Ctrl + Enter` | Insert line below |
| `Ctrl + Shift + Enter` | Insert line above |
| `Ctrl + Shift + \` | Jump to matching bracket |
| `Ctrl + ]` / `Ctrl + [` | Indent/outdent line |
| `Home` / `End` | Go to beginning/end of line |
| `Ctrl + Home` | Go to beginning of file |
| `Ctrl + End` | Go to end of file |
| `Ctrl + /` | Toggle line comment |
| `Shift + Alt + A` | Toggle block comment |

## Navigation
| Shortcut | Action |
|----------|--------|
| `Ctrl + F` | Find |
| `Ctrl + H` | Replace |
| `F3` / `Shift + F3` | Find next/previous |
| `Alt + Enter` | Select all occurrences of Find match |
| `Ctrl + D` | Add selection to next Find match |
| `Ctrl + K, Ctrl + D` | Move last selection to next Find match |
| `Ctrl + G` | Go to line... |
| `Ctrl + Shift + O` | Go to Symbol |
| `Ctrl + Shift + M` | Show Problems panel |
| `F8` / `Shift + F8` | Go to next/previous error or warning |
| `Ctrl + Shift + .` / `/` | Go to next/previous editor group |

## Multi-Cursor
| Shortcut | Action |
|----------|--------|
| `Ctrl + Shift + L` | Select all occurrences of current word |
| `Ctrl + F2` | Select all occurrences of current word |
| `Shift + Alt + I` | Insert cursor at end of each line selected |
| `Ctrl + Shift + Alt + Arrow` | Column (box) selection |

## Rich Language
| Shortcut | Action |
|----------|--------|
| `F12` | Go to Definition |
| `Alt + F12` | Peek Definition |
| `Ctrl + K, F12` | Open Definition to the side |
| `Ctrl + .` | Quick Fix |
| `Shift + F12` | Show References |
| `F2` | Rename Symbol |
| `Ctrl + K, Ctrl + X` | Remove trailing whitespace |
| `Ctrl + K, M` | Change language mode |

## Editor Management
| Shortcut | Action |
|----------|--------|
| `Ctrl + F4`, `Ctrl + W` | Close editor |
| `Ctrl + K, F` | Close folder |
| `Ctrl + \` | Split editor |
| `Ctrl + 1/2/3` | Focus into 1st, 2nd, 3rd editor group |
| `Ctrl + K, Ctrl + ←/→` | Focus into previous/next editor group |
| `Ctrl + Shift + PageUp/PageDown` | Move editor left/right |
| `Ctrl + Tab` | Open next editor |
| `Ctrl + Shift + Tab` | Open previous editor |

## File Management

| `Ctrl + Shift + S` | Save As |

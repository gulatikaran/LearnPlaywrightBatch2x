# Visual Studio Code Keyboard Shortcuts (macOS)

## General
| Shortcut | Action |
|----------|--------|
| `Cmd + Shift + P`, `F1` | Show Command Palette |
| `Cmd + P` | Quick Open, Go to File |
| `Cmd + Shift + N` | New Window |
| `Cmd + W` | Close Window |
| `Cmd + ,` | Open Settings |
| `Cmd + K, Cmd + S` | Open Keyboard Shortcuts |

## Basic Editing
| Shortcut | Action |
|----------|--------|
| `Cmd + X` | Cut line (empty selection) |
| `Cmd + C` | Copy line (empty selection) |
| `Option + ↓/↑` | Move line down/up |
| `Shift + Option + ↓/↑` | Copy line down/up |
| `Cmd + Shift + K` | Delete line |
| `Cmd + Enter` | Insert line below |
| `Cmd + Shift + Enter` | Insert line above |
| `Cmd + Shift + \` | Jump to matching bracket |
| `Cmd + ]` / `Cmd + [` | Indent/outdent line |
| `Home` / `End` | Go to beginning/end of line |
| `Cmd + Home` | Go to beginning of file |
| `Cmd + End` | Go to end of file |
| `Cmd + /` | Toggle line comment |
| `Shift + Option + A` | Toggle block comment |

## Navigation
| Shortcut | Action |
|----------|--------|
| `Cmd + F` | Find |
| `Cmd + H` | Replace |
| `F3` / `Shift + F3` | Find next/previous |
| `Option + Enter` | Select all occurrences of Find match |
| `Cmd + D` | Add selection to next Find match |
| `Cmd + K, Cmd + D` | Move last selection to next Find match |
| `Ctrl + G` | Go to line... |
| `Cmd + Shift + O` | Go to Symbol |
| `Cmd + Shift + M` | Show Problems panel |
| `F8` / `Shift + F8` | Go to next/previous error or warning |
| `Cmd + Shift + .` / `/` | Go to next/previous editor group |

## Multi-Cursor
| Shortcut | Action |
|----------|--------|
| `Cmd + Shift + L` | Select all occurrences of current word |
| `Cmd + F2` | Select all occurrences of current word |
| `Shift + Option + I` | Insert cursor at end of each line selected |
| `Cmd + Shift + Option + Arrow` | Column (box) selection |

## Rich Language
| Shortcut | Action |
|----------|--------|
| `F12` | Go to Definition |
| `Option + F12` | Peek Definition |
| `Cmd + K, F12` | Open Definition to the side |
| `Cmd + .` | Quick Fix |
| `Shift + F12` | Show References |
| `F2` | Rename Symbol |
| `Cmd + K, Cmd + X` | Remove trailing whitespace |
| `Cmd + K, M` | Change language mode |

## Editor Management
| Shortcut | Action |
|----------|--------|
| `Cmd + W` | Close editor |
| `Cmd + K, F` | Close folder |
| `Cmd + \` | Split editor |
| `Cmd + 1/2/3` | Focus into 1st, 2nd, 3rd editor group |
| `Cmd + K, Cmd + ←/→` | Focus into previous/next editor group |
| `Cmd + Shift + PageUp/PageDown` | Move editor left/right |
| `Cmd + Tab` | Open next editor |
| `Cmd + Shift + Tab` | Open previous editor |

## File Management
| Shortcut | Action |
|----------|--------|
| `Cmd + N` | New File |
| `Cmd + O` | Open File |
| `Cmd + S` | Save |
| `Cmd + Shift + S` | Save As |
| `Cmd + K, S` | Save All |
| `Cmd + W` | Close |

## Display
| Shortcut | Action |
|----------|--------|
| `Ctrl + Cmd + F` | Toggle full screen |
| `Cmd + K, Z` | Toggle zen mode |
| `Cmd + B` | Toggle sidebar visibility |
| `Cmd + J` | Toggle panel visibility |
| `Cmd + Shift + E` | Show Explorer |
| `Cmd + Shift + F` | Show Search |
| `Ctrl + Shift + G` | Show Source Control |
| `Cmd + Shift + D` | Show Debug |
| `Cmd + Shift + X` | Show Extensions |
| `Cmd + =/-` | Zoom in/out |

## Terminal
| Shortcut | Action |
|----------|--------|
| `` Ctrl + ` `` | Toggle terminal |
| `` Cmd + Shift + ` `` | Create new terminal |
| `Cmd + C` | Copy selection |
| `Cmd + V` | Paste into active terminal |

## Debugging
| Shortcut | Action |
|----------|--------|
| `F9` | Toggle breakpoint |
| `F5` | Start/continue debugging |
| `Shift + F5` | Stop debugging |
| `F11` / `Shift + F11` | Step into/out |
| `F10` | Step over |
| `Cmd + K, Cmd + I` | Show hover |
